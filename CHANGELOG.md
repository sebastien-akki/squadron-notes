## 0.2.0 · 2026-11-24

- Pin a note to keep it at the top of the list.
- Read a note with its Markdown shown: headings, lists, bold and code, and checklists you tick with one click.
- Put in my message sends only the selected text when there is a selection.
- Escape goes back to the list.

## 0.1.0 · 2026-11-20

- First version: private notes for each project in a panel next to your agents, saved as you type.
- Put a note in your message in one click.
- Agents can list, read and add to the notes of their project with `notes_list`, `notes_read` and `notes_append`.
